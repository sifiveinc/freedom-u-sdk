# Release Notes for 2026.10

This Release includes major changes compared previous Freedom-U-SDK (FUSDK) release. The notable changes include:

- Added new machine ("hifive-premier-p550") for HiFive Premier P550 board.
- Added below recipes to support new machine hifive-premier-p550
    + Kernel. Version is `6.12.33`.
    + U-Boot. Version is `2024.01`.
    + boot-image - To generate vfat image comprising of Kernel Image, DTB and extlinux.conf.
    + bootchain - To generate bootloader image combining ddr-fw, Second Boot fw, OpenSBI and U-Boot.
    + nsign - Tool used to generate bootchain image.
- Include additional patches in OpenSBI for HiFive Premier P550.
- OpenSBI version is still `1.9`.
- No version updates have been made to kernel, OpenSBI and U-Boot for HiFive Unleashed and Unmatched board.
- Below new packages are added for HiFive Premier P550 board.
    + Add custom fancontrol config to support fan speed control for onboard fan based on SoC temperature.
    + Add supertuxkart game. Version is `1.5`.
    + Add es-bmcd recipe that adds daemon used for communication between SoC and MCU via UART.
    + Remove osc-context from PACKAGECONFIG to avoid annoying message displayed each time we press "Enter" key if using the terminal (e.g. minicom) that cannot deal with this OSC 3008 standard.
    + Add additional user packages to rootfs required for HiFive Premier P550 board.
- Updated DISTRO_VERSION and DISTRO_CODENAME.

## Known Issues for HiFive Premier P550

- On executing a reboot command with external GFX connected, sometimes, the board reboot hangs.
- Bus error reported from UART driver at startup. This will be addressed in the subsequent releases.

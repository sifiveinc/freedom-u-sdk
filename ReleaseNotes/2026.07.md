# Release Notes for 2026.07.00-lts

## 2026.07.00-lts

This release includes major changes compared previous Freedom-U-SDK (FUSDK)
release. The notable changes include:
- Layers and Bitbake have been updated and are compatible with Wrynose.
- Some packages have been updated.
- Some bugs and security issues have been fixed.
- GCC is still 15.2.0.
- LLVM has been updated from 21.1.8 to 22.1.3.
- Binutils has been updated from 2.45 to 2.46.
- Glibc has been updated from 2.42 to 2.43.
- GDB has been updated from 16.3 to 17.1.
- Mesa has been updated from 25.2.5 to 26.0.5.
- OpenSBI is still 1.8.1.
- U-Boot is still 2026.01.
- Linux kernel longterm is still 6.18.3.
- Linux headers have been updated from 6.17 to 6.18.
- Python3 has been updated from 3.13.9 to 3.14.4.
- Xfce4 is still 4.20.0.
